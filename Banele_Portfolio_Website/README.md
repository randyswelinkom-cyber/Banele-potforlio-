# Banele Portfolio

A self-contained static portfolio website for GitHub Pages.

## Files
- `index.html` — main website
- `style.css` — layout, typography and responsive styling
- `script.js` — small navigation interaction
- `assets/portfolio-reference.png` — visual reference image recovered from the portfolio work

## GitHub Pages
Upload the contents of this folder to the **root** of your repository. The homepage file must be named exactly:

`index.html`

Then use:
**Settings → Pages → Deploy from a branch → main → /(root)**

The site is designed to work as a static GitHub Pages site with no build step.
